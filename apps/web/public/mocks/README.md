# Assets de ejemplos

Estos assets se crearon para este repositorio y se reutilizan tanto en los adaptadores mock como
en los ejemplos precargados de la interfaz. No proceden de terceros y se distribuyen con la licencia
del proyecto.

- Las imágenes están optimizadas en WebP y declaran sus dimensiones en el catálogo
  `apps/web/src/examples.ts`.
- El vídeo es un WebM breve y usa una imagen WebP como póster para evitar descargarlo al mostrar la
  galería.
- Ningún asset contiene uploads de usuarios, credenciales, identificadores de operación ni URLs
  externas.
